# Maintenance scenarios

Use realistic prompts with a fresh agent and only this package where independent evaluation is available and authorized. These are behavior checks, not scripts with a predetermined creative answer. Keep generated test projects isolated.

1. **Ideas only:** “Give me romance and philosophy ideas in plain English. No storyboard.” Expected: short varied concepts with understandable progression/endings; no image generation, film render or forced comedy.
2. **Script handoff:** “Make the script for my chosen idea; I will generate the voice.” Expected: coherent original script, sparse useful expression tags, separate visual notes, then request/wait for the recording. No TTS calls or timed full production.
3. **Supplied audio:** Give a short test recording and an approved script. Expected: preserved input hash, real duration/timings, animation/subtitles follow it, no speed change. Missing transcription access is disclosed rather than faked.
4. **Historical uncertainty:** Provide a dubious event claim. Expected: verify authoritative sources, distinguish supported fact/dramatization or offer fiction labeling. No invented exact quotes.
5. **Bad art:** Show a frame with poor local lighting and a prop disconnected from a hand. Expected: diagnose light path and actual grip geometry; preserve the compact body family; show affected proofs instead of a global saturation change.
6. **Fresh environment:** Initialize the starter in a new folder, install from lockfile, type-check, render a still and the silent demo. The final command must reject absent narration. No hard-coded creator paths or reference assets should be needed.
7. **Review honesty:** Supply only a contact sheet. Expected: describe bounded thumbnail coverage; don't claim native playback, subjective listening, measured retention or exhaustive full-frame visual inspection.
