# Visual and technical review

## Before a long render

Tailor proofs to the film; one integrated test can cover several questions. Establish the relevant original character views, readable set/material composition, local-light response and a short important action/camera sequence through the actual rendering path. Use caption-free originals, equal subject-scale comparisons, native details and phone previews. A preview that was not shown cannot be a useful user review request.

Judge distinct categories explicitly: character family/form; expression and facing; set construction and depth; targeted palette; materials; motivated light/shadow; contact and action; camera clarity; story/reveal. An overall score cannot hide a weak category. Fix the specific failure and repeat the affected proof, not an endless collection of unrelated tests.

## Encoded output

Review the actual exported file, including held poses and the first/last spoken words. Inspect chronological sheets, selected native frames, cut boundaries and short action sequences. Check subtitle coverage and text collisions. Play the final audio/video when available. State which checks were actually performed; thumbnails, metrics and transcripts are not full-resolution playback or subjective listening.

Check duration/frame count, dimensions/fps, codec/pixel format, audio presence and decode errors. Candidate black/white/frozen frames and image-difference spikes need interpretation: intentional cuts, holds and fades are valid. Do not add ornamental motion to evade a freeze detector.

Review contacts natively: hands/supports, grips, prop depth ordering, feet, view transitions and newly revealed evidence. After final resizing, verify contours, glyphs and all important labels at phone size. Review with captions both on and off.

Fade with an opaque black/background overlay. Changing whole-frame alpha can leave RGB brightness unchanged once video encoding discards alpha. Verify the encoded ending's actual RGB/luma behavior.

## Repairing a render

For a bounded repair, use explicit inclusive source-frame ranges and preserve the original frame indices. Verify frame count and both splice boundaries. Check that retained frame order and intended audio are unchanged; keep the existing audio stream where feasible. Render caches and source edits alone do not prove the repaired file contains the fix.

If static CanvasTexture actors disappear, inspect refresh/resource lifecycles and the final encoded frames. Avoid asserting an unproven GPU cause. A fresh short proof and repaired output must show the actual result.

## Acceptance

Technical integrity is necessary but separate from story/art quality. Do not claim a percentage reference match, superior quality, exhaustive native review or listening that was not performed. Name material remaining gaps and review limits. Deliver original production assets and findings, never private inspiration media. Keep fixes confined to the current authorized film/phase.
